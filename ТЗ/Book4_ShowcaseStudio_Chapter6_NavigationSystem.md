# UniListView Developer Guide

## Book 4. Showcase Studio

# Глава 6. Navigation System --- архитектура навигации

------------------------------------------------------------------------

# Введение

Даже самая богатая коллекция демонстраций бесполезна, если разработчик
не может быстро найти нужный пример.

Navigation System --- одна из ключевых подсистем Showcase Studio. Она
обеспечивает мгновенный доступ к любой сцене независимо от общего
количества демонстраций.

Основной принцип системы навигации --- *разработчик должен находить
нужный пример быстрее, чем успеет вспомнить его название.*

------------------------------------------------------------------------

# Цели навигации

Навигационная система должна обеспечивать:

-   логичную структуру;
-   минимальное количество действий до открытия сцены;
-   быстрый поиск;
-   историю переходов;
-   избранные демонстрации;
-   единое поведение на всех платформах;
-   возможность масштабирования до тысяч сцен.

------------------------------------------------------------------------

# Основные элементы

Навигация включает следующие подсистемы:

-   дерево категорий;
-   строку поиска;
-   список результатов;
-   панель избранного;
-   историю;
-   хлебные крошки;
-   быстрый переход;
-   горячие клавиши.

------------------------------------------------------------------------

# Дерево категорий

Основной способ изучения Showcase.

Пример структуры:

    Getting Started
    Basic Controls
    Selection
    Columns
    Editing
    Data Sources
    Virtual Mode
    Styling
    Themes
    Performance
    Diagnostics
    Advanced
    Experimental

Категории должны быть стабильными и редко изменяться.

------------------------------------------------------------------------

# Подкатегории

Если количество сцен становится слишком большим, допускается вложенная
структура.

Например:

    Columns
        Basic
        Resize
        Reorder
        Frozen
        Templates

Глубина дерева должна оставаться разумной.

Рекомендуется не более трёх уровней.

------------------------------------------------------------------------

# Поиск

Поиск является вторым основным способом навигации.

Он должен работать одновременно по:

-   названию;
-   описанию;
-   тегам;
-   категории;
-   идентификатору сцены.

Результаты обновляются по мере ввода текста.

------------------------------------------------------------------------

# Теги

Теги позволяют объединять сцены независимо от структуры дерева.

Например:

    animation
    sorting
    filter
    touch
    performance
    dark
    virtual

Одна сцена может принадлежать десяткам тегов.

------------------------------------------------------------------------

# История

Navigation хранит историю открытия демонстраций.

Например:

    Basic List
    ↓

    Selection
    ↓

    Columns
    ↓

    Virtual Mode

История позволяет быстро возвращаться к ранее просмотренным сценам.

------------------------------------------------------------------------

# Избранное

Разработчик может закрепить наиболее полезные демонстрации.

Пример:

⭐ Basic List

⭐ Virtual Mode

⭐ Custom Painting

⭐ Million Rows

Избранное хранится в пользовательских настройках.

------------------------------------------------------------------------

# Хлебные крошки

При открытии сцены пользователь всегда видит её положение.

Например:

    Home
     /
    Performance
     /
    Virtual Mode
     /
    Million Rows

Это особенно полезно при использовании поиска.

------------------------------------------------------------------------

# Горячие клавиши

Рекомендуется поддерживать:

-   Ctrl+K --- поиск;
-   Ctrl+F --- поиск внутри описания;
-   Alt+← --- назад;
-   Alt+→ --- вперёд;
-   Ctrl+D --- добавить в избранное;
-   Esc --- очистить поиск.

Все комбинации должны одинаково работать на всех поддерживаемых
платформах.

------------------------------------------------------------------------

# Быстрый переход

Для опытных пользователей полезен режим Command Palette.

Например:

    > virtual

Сразу отображаются все сцены, связанные с виртуальным режимом.

Такой подход значительно ускоряет работу с большими Showcase.

------------------------------------------------------------------------

# Производительность

Навигация должна оставаться мгновенной даже при наличии тысяч сцен.

Рекомендуется:

-   предварительно индексировать теги;
-   использовать словари для поиска по ID;
-   выполнять фильтрацию без обращения к Scene Host;
-   не создавать экземпляры сцен при отображении списка результатов.

------------------------------------------------------------------------

# Локализация

Все пользовательские строки должны быть локализуемыми.

При этом:

-   идентификаторы остаются неизменными;
-   теги могут иметь внутреннее и локализованное представление;
-   поиск должен поддерживать локализованные названия.

------------------------------------------------------------------------

# UX-принципы

Хорошая навигация обладает следующими свойствами:

-   предсказуемость;
-   отсутствие скрытых разделов;
-   единая логика поведения;
-   минимальное количество кликов;
-   быстрый отклик;
-   визуальная простота.

------------------------------------------------------------------------

# Антипаттерны

Следует избегать:

-   чрезмерной глубины дерева;
-   дублирования категорий;
-   неоднозначных названий;
-   длинных списков без поиска;
-   динамического изменения структуры без необходимости.

------------------------------------------------------------------------

# Итоги

Navigation System является связующим звеном между пользователем и всеми
демонстрациями Showcase Studio.

Продуманная архитектура навигации позволяет легко ориентироваться даже в
очень больших коллекциях примеров, превращая Showcase Studio в
полноценную интерактивную энциклопедию UniListView.

Следующая глава посвящена встроенной системе документации: описаниям
сцен, встроенным справочным материалам, отображению исходного кода и
интеграции документации с демонстрациями.
