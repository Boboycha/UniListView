# UniListView Developer Guide

## Book 4. Showcase Studio

# Глава 9. Theme Manager --- архитектура системы оформления

------------------------------------------------------------------------

# Введение

Визуальное оформление является неотъемлемой частью Showcase Studio.
Независимо от сложности демонстрационной сцены пользователь должен
воспринимать приложение как единый продукт с последовательным стилем.

Theme Manager отвечает за централизованное управление внешним видом всех
элементов интерфейса и обеспечивает единое оформление независимо от
текущей демонстрации.

------------------------------------------------------------------------

# Цели Theme Manager

Подсистема оформления должна обеспечивать:

-   единый стиль приложения;
-   мгновенное переключение тем;
-   отсутствие мерцания при смене оформления;
-   поддержку пользовательских тем;
-   единый набор цветов;
-   единые размеры и отступы;
-   независимость демонстраций от конкретной темы.

------------------------------------------------------------------------

# Архитектура

    Application
          │
          ▼
     Theme Manager
          │
     ┌────┼─────────────┐
     ▼    ▼             ▼
    Colors Fonts     Metrics
          │
          ▼
     Active Scene

Все обращения к оформлению выполняются через Theme Manager.

------------------------------------------------------------------------

# Базовые сущности

Theme Manager управляет несколькими наборами данных:

-   палитрой цветов;
-   типографикой;
-   размерами элементов;
-   отступами;
-   радиусами скругления;
-   иконками;
-   параметрами анимации.

Разделение облегчает создание новых тем.

------------------------------------------------------------------------

# Светлая и тёмная темы

Минимальный набор включает две встроенные темы:

-   Light;
-   Dark.

Переключение должно происходить без перезапуска Showcase Studio и без
пересоздания демонстрационной сцены.

------------------------------------------------------------------------

# Пользовательские темы

Архитектура должна позволять создавать собственные темы оформления.

Пользовательская тема может переопределять:

-   цвета;
-   шрифты;
-   размеры;
-   набор иконок;
-   параметры анимации.

При этом логика работы сцен остаётся неизменной.

------------------------------------------------------------------------

# Палитра

Рекомендуется использовать семантические цвета вместо фиксированных
значений.

Например:

-   Background;
-   Surface;
-   Border;
-   Primary;
-   Secondary;
-   Accent;
-   Success;
-   Warning;
-   Error;
-   DisabledText.

Такой подход облегчает адаптацию под различные темы.

------------------------------------------------------------------------

# Типографика

Все размеры шрифтов определяются централизованно.

Например:

-   Caption;
-   Body;
-   Subtitle;
-   Heading;
-   Title.

Сцены не должны использовать произвольные значения без необходимости.

------------------------------------------------------------------------

# Иконография

Theme Manager предоставляет единый доступ к набору иконок.

Это позволяет:

-   заменить набор целиком;
-   использовать SVG;
-   переключаться между светлыми и тёмными вариантами;
-   масштабировать изображения в зависимости от DPI.

------------------------------------------------------------------------

# Интеграция с FMX

Theme Manager не заменяет FMX Styles, а дополняет их.

FMX отвечает за базовое оформление компонентов, а Theme Manager
предоставляет логический уровень оформления приложения.

Это позволяет сохранить независимость Showcase Studio от конкретного
визуального стиля FMX.

------------------------------------------------------------------------

# Реакция на смену темы

После переключения темы Theme Manager уведомляет все заинтересованные
компоненты.

Типичный порядок:

1.  изменение активной темы;
2.  обновление палитры;
3.  обновление ресурсов;
4.  уведомление Scene Host;
5.  перерисовка активной сцены.

------------------------------------------------------------------------

# Производительность

Изменение темы не должно приводить к повторной загрузке данных сцены.

Изменяется только визуальное представление.

Это обеспечивает быстрое переключение даже для сложных демонстраций.

------------------------------------------------------------------------

# Локальное переопределение

В отдельных случаях сцена может временно изменить отдельные параметры
оформления.

Например:

-   подсветить область;
-   показать предупреждение;
-   использовать специальную цветовую схему.

После завершения демонстрации управление снова возвращается Theme
Manager.

------------------------------------------------------------------------

# Лучшие практики

Рекомендуется:

-   использовать семантические цвета;
-   хранить параметры темы централизованно;
-   минимизировать количество жёстко заданных значений;
-   тестировать все сцены в каждой теме;
-   поддерживать одинаковый внешний вид на всех платформах.

------------------------------------------------------------------------

# Антипаттерны

Следует избегать:

-   жёстко прописанных RGB-значений;
-   прямого обращения к ресурсам FMX из бизнес-логики;
-   хранения параметров оформления внутри демонстрационных сцен;
-   различного поведения одной и той же сцены в разных темах.

------------------------------------------------------------------------

# Итоги

Theme Manager обеспечивает единое визуальное пространство Showcase
Studio и отделяет оформление от логики демонстраций. Благодаря
централизованному управлению темами библиотека сохраняет
профессиональный внешний вид, легко адаптируется под разные платформы и
остаётся удобной для дальнейшего развития.

Следующая глава будет посвящена Diagnostics Framework --- встроенной
системе диагностики, профилирования и анализа производительности
Showcase Studio.
